# NexusMart

Full-stack tech-commerce platform.

## Tech Stack

- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS v4
- **Database:** PostgreSQL
- **Payments:** Stripe
